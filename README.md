# 库存管理系统

一套给仓库、生产和配货人员使用的标签打印与库存管理软件。

只需要在一台电脑上运行软件，其他同事用浏览器就能一起使用，不用每台电脑都安装。系统支持标签打印、入库、出库、库存查询、配货单、送货单和操作记录。

> 当前版本：`2.5.6`

## 先看这里：5 分钟上手

### 你是哪类用户？

| 你的情况 | 从哪里开始 |
| --- | --- |
| 第一次安装、负责维护系统 | 看 [管理员首次配置](#管理员首次配置) |
| 软件已经装好，只负责日常操作 | 看 [普通用户登录](#普通用户登录) |
| 只想打印标签 | 看 [打印第一张标签](#打印第一张标签) |
| 其他电脑打不开系统 | 看 [其他电脑无法访问](#其他电脑无法访问) |

### 使用前准备

- 一台长期运行软件的电脑，作为“主机”
- 标签打印机及对应驱动
- 如果多人使用，所有电脑连接同一个公司网络、路由器或 Wi-Fi
- 管理员提供的账号、密码和访问地址

### 最简单的使用流程

1. 主机双击打开“库存管理系统”。
2. 等待登录页面出现，不要关闭软件窗口。
3. 使用管理员提供的账号登录。
4. 在左侧菜单选择“标签打印”“入库”“出库”或“配货单”。
5. 其他电脑在浏览器输入主机窗口标题中的地址，例如 `http://192.168.1.100:3456`。

> 主机退出软件、关机、休眠或断开网络后，其他电脑将无法继续使用。

## 安装与启动

### Windows

1. 获取 `.exe` 安装包并双击运行。
2. 按安装向导完成安装，可以自行选择安装位置。
3. 从桌面或开始菜单打开“库存管理系统”。
4. 如果 Windows 防火墙询问是否允许访问网络，请勾选“专用网络”并点击“允许访问”。

如果 Windows 提示安装包来源未知，请先向软件提供者确认文件来源，再选择继续运行。

### macOS

1. 获取 `.dmg` 安装包并双击打开。
2. 将“库存管理系统”拖入“应用程序”。
3. 从“应用程序”中打开软件。
4. 如果系统阻止打开，请前往“系统设置 → 隐私与安全性”，确认该安装包可信后允许打开。

### Linux

获取 `.AppImage` 文件后添加执行权限并运行：

```bash
chmod +x 库存管理系统-*.AppImage
./库存管理系统-*.AppImage
```

### 其他电脑怎么进入系统？

主机启动后，窗口标题会显示类似地址：

```text
库存管理系统 - 其他电脑请访问 http://192.168.1.100:3456
```

在其他电脑上打开 Chrome、Edge、Firefox 或 Safari，把 `http://192.168.1.100:3456` 输入浏览器地址栏即可。地址以主机实际显示的内容为准，端口不一定总是 `3456`。

## 账号与登录

### 普通用户登录

1. 打开管理员提供的访问地址。
2. 输入用户名和密码。
3. 点击“登录”。

登录状态通常保持 24 小时。出现“登录已过期”时，重新登录即可。

### 默认管理员账号

系统第一次启动会自动创建管理员账号：

| 项目 | 默认值 |
| --- | --- |
| 用户名 | `admin` |
| 密码 | `admin123` |

> 第一次登录后，请立即点击左下角用户名 → “修改密码”。不要长期使用默认密码。

### 忘记密码怎么办？

- 普通用户：联系管理员，在“用户管理”中重置密码。
- 管理员：优先让另一名管理员重置密码。
- 如果没有其他管理员，请联系软件维护人员处理。

不要为了找回密码直接删除数据库。数据库中包含物料、库存、账号和业务记录，删除后会造成数据丢失。

## 打印第一张标签

### 1. 连接打印机

先在操作系统中安装打印机驱动，并打印一张测试页，确认电脑能够正常识别打印机。

标签规格：

- 小标签（袋装）：50 × 40 mm
- 大标签（箱装）：90 × 70 mm

### 2. 选择物料

1. 打开左侧“标签打印”。
2. 输入物料号、名称或规格，也可以直接用扫码枪扫描。
3. 在搜索结果中点击“选择”。
4. 填写标签数量、订单号、工程名称等信息。
5. 选择“小标签（袋）”或“大标签（箱）”。
6. 检查右侧预览。

### 3. 确认是否扣库存

页面默认勾选“不计入库存”，此时打印不会改变库存。

- 只补打标签或测试打印：保持勾选“不计入库存”。
- 打印同时代表物料出库：取消勾选，并核对按钮上显示的扣减数量。

系统允许负库存，因此点击打印前一定要确认选项和数量。

### 4. 打印

- 在主机桌面软件中：点击“打印机设置”，分别给小标签和大标签选择打印机；保存后可直接发送到对应打印机。
- 在其他电脑的浏览器中：点击打印后会出现浏览器或系统打印窗口，需要手动选择本机打印机。

第一次打印建议只打 1 张，并检查：

- 纸张尺寸正确
- 缩放为 100% 或“实际大小”
- 边距为“无”或最小
- 已启用“背景图形”
- 打印方向和内容位置正确

### 其他标签入口

| 菜单 | 适用场景 |
| --- | --- |
| 标签打印 | 常规小标签、大标签 |
| 打包标签 | 打包场景使用的版式 |
| 双语标签 | 展示中英文描述的大标签 |
| 双语拼箱标签 | 多个物料拼箱并展示双语信息 |

## 日常功能怎么用

### 入库

1. 打开“入库”。
2. 搜索或扫码找到物料。
3. 输入入库数量。
4. 填写备注，例如采购单号或到货批次。
5. 点击“确认入库”。

大量数据可使用“Excel 批量入库”，上传后先检查预览，再确认导入。

### 出库

1. 打开“出库”。
2. 搜索或扫码找到物料。
3. 输入出库数量和备注。
4. 点击“确认出库”。

系统允许负库存。出现负数时，应检查是否漏做入库、重复出库或打印时错误扣减。

### 库存

需要“库存查看权限”。

- “表格”用于搜索物料和查看当前库存。
- “仪表盘”“趋势”“配单用量”用于查看汇总情况。
- “修改”可手动调整库存，必须填写原因。
- “批量导入库存”适合初始化或批量校准。

手动修改前建议先确认实物数量。每次修改都会留下操作记录。

### 配货单

1. 打开“配货单”。
2. 扫描或输入单号，点击“查询”。
3. 勾选要处理的物料。
4. 根据需要选择：

   - “拼箱”：组合标签并跳转到标签打印
   - “统一出库”：批量完成出库，需要“配货出库权限”
   - “一键打印”：将所选标签送入打印队列，不扣库存
   - “导出送货单”：下载 Excel 送货单

已出库或部分出库的条目可以“重置”。重置会恢复库存并清除对应的配货状态，操作前请确认该批物料确实需要撤回。

### 拼送货单

1. 打开“拼送货单”，点击“增加物料”。
2. 输入订单号并查询。
3. 勾选需要的行，点击“确认增加”。
4. 可以继续添加其他订单。
5. 核对清单后点击“导出拼送货单”。

导出后会尝试把相关条目标记为已打印送货单。若页面提示标记失败，请不要重复出货，先核对下载文件和订单状态。

### 物料库

需要“数据管理权限”或管理员权限。

- 新增、编辑、删除物料
- 维护中文描述和英文描述
- 上传、查看和排序物料图纸
- 使用 Excel 批量导入

删除物料会影响当前库存和图纸数据。批量删除或清空前应先备份。

### 操作记录与撤销

入库、出库、打印扣库和手动调整都会记录操作人、数量及时间。有库存权限的用户可在相关页面查看记录。

撤销会反向恢复库存。请只撤销确实发生错误的记录，不要把“撤销”当作新的入库或出库操作。

## Excel 导入

### 使用建议

1. 第一行必须是表头。
2. 物料号和数量不要留空。
3. 不要合并单元格。
4. 数量列使用数字，不要附带“只”“千”等单位文字。
5. 先用少量数据试导入。
6. 务必检查系统提供的导入预览和错误提示。

### 常用表头

**物料库**

| 字段 | 是否必填 | 可识别的常见表头 |
| --- | --- | --- |
| 物料号 | 必填 | 物料号、物品编码、编码、code |
| 名称 | 必填 | 物品名称、名称、name |
| 中文描述 | 选填 | 物料描述、描述 |
| 英文描述 | 选填 | 英文描述、英文、description_en、Description EN |
| 其他 | 选填 | 规格、等级、表面处理、材质、特殊备注 |

**批量入库 / 出库**

| 字段 | 是否必填 | 可识别的常见表头 |
| --- | --- | --- |
| 物料号 | 必填 | 物料号、code |
| 数量 | 必填 | 数量、quantity |
| 备注 | 选填 | 备注、remark |

**批量库存**

| 字段 | 是否必填 | 可识别的常见表头 |
| --- | --- | --- |
| 物料号 | 必填 | 物料号、code |
| 库存 | 必填 | 库存、数量、quantity |

配货单包含的字段较多，建议从系统中导出一份现有订单作为参考，再按相同表头整理后导入。

## 管理员首次配置

建议按以下顺序完成：

1. 使用 `admin` / `admin123` 登录。
2. 立即修改管理员密码。
3. 在“物料库”中导入或创建物料。
4. 在“用户管理”中为同事创建独立账号。
5. 按岗位分配权限。
6. 连接打印机，在“标签打印 → 打印机设置”中完成映射。
7. 用测试物料分别测试入库、出库和大小标签。
8. 告诉同事访问地址，并保证主机不会自动休眠。
9. 制定数据库和图纸文件的定期备份方案。

### 权限说明

| 权限 / 角色 | 可以做什么 |
| --- | --- |
| 普通用户 | 登录、打印、查询配货单、使用拼送货单 |
| 库存查看权限 | 查看库存和记录，进行入库、出库、库存调整，并新增、编辑、删除或导入配货单数据 |
| 数据管理权限 | 进入物料库，新增、编辑、删除和导入物料 |
| 配货出库权限 | 在配货单中执行统一出库、部分出库、重置出库等会改变配货和库存状态的操作 |
| 管理员 | 拥有全部权限，还可管理用户、清空数据和配置开放接口 |

建议每人使用自己的账号，便于操作追溯；不要多人共用管理员账号。

### 开放接口

管理员可在“开放接口”页面启用只读接口、轮换 Token、配置 IP 白名单，并复制给 Codex 的接入说明。

接口仅建议由了解网络和鉴权的管理员配置。详细说明见 [开放接口文档](docs/open-api-guide.md)。

## 常见问题

### 其他电脑无法访问

按顺序检查：

1. 主机上的软件是否仍在运行。
2. 两台电脑是否连接同一个局域网。
3. 浏览器地址是否与主机窗口标题完全一致。
4. 主机是否进入睡眠或更换了网络。
5. Windows 防火墙是否允许“库存管理系统”访问专用网络。
6. 如果地址末尾不是 `3456`，应使用软件实际显示的端口。

公司网络可能开启“设备隔离”，导致同一 Wi-Fi 下的设备也无法互相访问。上述检查无效时，请联系网络管理员。

### 打印机列表为空

1. 检查打印机电源、USB 或网络连接。
2. 在系统设置中确认已经安装打印机。
3. 先用系统自带的测试页验证驱动。
4. 重新打开库存管理系统。

浏览器访问时无法使用主机桌面端保存的打印机映射，应在弹出的打印窗口中选择浏览器所在电脑的打印机。

### 打印尺寸、位置或清晰度不对

- 标签纸与模板尺寸必须匹配：小标签 50 × 40 mm，大标签 90 × 70 mm。
- 缩放选择 100% 或“实际大小”，不要选择“适合页面”。
- 边距选择“无”或最小。
- 开启“背景图形”。
- 检查打印机驱动中的纸张规格、方向、浓度和速度。
- 先打印 1 张校准，不要直接批量打印。

### 打印后库存没有变化

检查打印页面是否勾选了“不计入库存”。勾选时只打印，不扣库存。

配货单中的“一键打印”也不会扣库存；需要扣库存时，应使用“统一出库”或在标签打印页取消“不计入库存”后打印。

### 库存变成负数

系统允许负库存。常见原因包括漏做入库、重复出库、打印时取消了“不计入库存”，或者实际库存不足。

先查看操作记录确认原因，再通过撤销错误记录、补做入库或手动调整修正，不建议直接反复修改库存数字。

### 软件打不开或提示端口占用

系统默认使用 `3456` 端口；如果端口已被占用，会自动尝试下一个端口。请以窗口标题显示的新地址为准。

如果软件完全无法启动，请截取完整错误信息，并记录操作系统版本、软件版本和刚才进行的操作，交给维护人员排查。

### 数据存在哪里？怎么备份？

业务数据保存在主机的系统用户数据目录中，数据库文件名为 `inventory-management.db`，物料图纸位于同目录的 `product-drawings` 文件夹。

备份前请先退出软件，再同时复制数据库文件和 `product-drawings` 文件夹到安全位置。恢复数据前也应先退出软件，并由维护人员操作，避免覆盖新数据。

## 给开发和维护人员

普通用户不需要执行本节命令。

### 本地开发

需要 Node.js 18 或更高版本（CI 使用 Node.js 22）以及对应平台的原生模块编译环境。

```bash
npm install
npm run dev
```

### 构建安装包

```bash
npm run build       # 仅构建
npm run pack        # 生成未打包程序
npm run dist        # 为当前平台生成安装包
npm run dist:win    # Windows NSIS 安装包
npm run dist:mac    # macOS DMG 安装包
```

安装包默认输出到 `dist` 目录。由于项目使用 `better-sqlite3` 原生模块，优先在目标操作系统上打包。

### 技术组成

- Electron + React + TypeScript
- Express 局域网服务
- SQLite（better-sqlite3）
- Ant Design
- SheetJS / ExcelJS
- electron-builder

### 服务配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SERVER_HOST` | `0.0.0.0` | 服务监听地址 |
| `SERVER_PORT` | `3456` | 起始端口；占用时自动尝试下一端口 |
| `OPEN_API_ENABLED` | 未设置 | 可选的开放接口总开关；应用内设置优先 |
| `OPEN_API_TOKEN` | 系统生成 | 可选固定 Token |
| `OPEN_API_ALLOWED_IPS` | 空 | 可选 IP 白名单，使用逗号分隔 |
| `OPEN_API_SCOPE` | `read:all` | 开放接口权限范围 |
