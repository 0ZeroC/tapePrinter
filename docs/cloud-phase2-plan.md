# 云端化二期方案（规划）

本文件描述第一期“客户本地部署 + 局域网开放接口”后的云端演进方向，不包含本期代码实施。

## 目标

- 支持跨地域访问与集中数据分析
- 保留客户现场部署能力，支持渐进迁移
- 面向管理层提供统一自然语言分析入口

## 推荐架构

1. 云端 API 网关（统一鉴权、限流、审计）
2. 多租户业务服务（按客户隔离）
3. 云端数据库（主存储）
4. 边缘同步代理（客户本地可选离线缓存）

## 关键设计点

- 租户隔离：`tenant_id` 贯穿用户、token、数据、日志
- 安全：TLS、短期 token、最小权限 scope、IP/设备约束
- 同步：本地->云端增量同步、冲突策略、可重放补偿
- 审计：操作日志、访问日志、AI 查询日志独立保存
- 合规：敏感字段脱敏、导出审计、数据保留策略

## 迁移路径

1. 保持现有 `/api/open/v1` 契约稳定（已完成）
2. 新增云端兼容层，复用相同只读接口语义
3. 为客户提供“本地模式 / 云端模式”切换
4. 最后按客户分批迁移，保留回退通道

## 风险与对策

- 网络不稳定：本地缓存 + 重试队列
- 数据一致性：幂等键 + 版本号 + 审计对账
- 成本上升：冷热分层存储 + 查询配额控制
