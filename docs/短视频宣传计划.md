# 短视频宣传计划（15～30 秒系列）

本文档说明当前短视频内容的**计划安排**、**设计原因**与**希望呈现的效果**，供拍摄、剪辑与投放对齐使用。产品指向：基于 Electron 的库存管理与标签打印系统（局域网多端浏览器访问）。

---

## 1. 目标与定位

| 项目 | 说明 |
|------|------|
| **核心目标** | 在极短时间内**博取注意力**，让观众停留并产生「和我有关」的印象；不强求单条讲全功能。 |
| **时长** | 单条 **15～30 秒**，适配抖音、视频号、B 站短视频等竖屏/横屏均可的版本。 |
| **系列策略** | **多条短片、同一产品、不同钩子**，避免一条长片信息过载，同时便于 A/B 测试哪类开场更有效。 |
| **受众** | 中小微企业管理者、仓库/生产现场负责人、对「Excel + 多个工具」感到疲惫的一线使用者。 |

---

## 2. 为什么采用「短、多、单点」

1. **注意力窗口短**：信息流里前几秒决定去留，必须把**反差、数字、动作或质问**放在开头，而不是先讲公司或功能列表。  
2. **一条一个记忆点**：全功能堆砌会被划走；每条只强化一个概念（例如：零安装协同、扫码打印、账实同步），**更易记住、更易转发**。  
3. **素材复用率高**：同一套录屏（登录、搜索、预览标签、浏览器访问、库存数字变化）可配**不同口播**，批量产出，降低制作成本。  
4. **与产品调性一致**：产品强调**现场效率、局域网协作、标签与库存一体**；短视频用「快、直接、有画面」比「像 ERP 说明书」更匹配。

---

## 3. 希望展示的效果（观感与信息）

### 3.1 整体观感

- **节奏**：前 1～2 秒必有「声画冲击」（扫码声、大字标题、快速切屏、质问句）。  
- **气质**：**现场感 + 清爽界面**，避免纯 PPT 式讲解；技术细节（端口、框架名）尽量不出现。  
- **结尾**：统一留 **0.5～1 秒定帧**（产品名 / Slogan / 一句行动暗示），方便品牌识别。

### 3.2 每条片子希望传递的「一条信息」（可轮换）

| 方向 | 希望观众带走的一句话 |
|------|------------------------|
| 痛点对比 | 库存不该散落在 Excel 和聊天记录里，需要一套对齐的现场工具。 |
| 部署方式 | 一台电脑跑服务，其他人**浏览器打开即用**，降低安装与推广成本。 |
| 核心动作 | **扫码 → 选量 → 预览 → 打印**，且打印与库存联动。 |
| 定制理念 | **系统适应企业习惯**，而非先强迫改流程再上大而全的 ERP。 |
| 信任与管控 | 出入库留痕、权限分工，减少扯皮（点到为止，不展开条款）。 |

实际拍摄时**每条只选其中一行**作为主线，其余用画面带过即可。

## 4. 系列脚本规划（概要）

| 脚本 | 时长倾向 | 钩子类型 | 侧重信息 |
|------|----------|----------|----------|
| **A** | 约 18～22 秒 | 痛点（Excel/混乱） | 多工具 → 一系统；浏览器访问 |
| **B** | 约 15～18 秒 | 数字/标题栏地址 | 一台服务端、全员在线、零安装 |
| **C** | 约 20～26 秒 | 动作（扫码打印） | 扫码到打印全流程；打印扣库存 |
| **D** | 约 22～28 秒 | 对立句式 | 系统适应人，而非人适应大而全 |
| **E** | 约 15～20 秒 | 质问 | 账实一致；留痕与协同 |
| **F** | 约 12～15 秒 | 金句快闪 | 工具太散 → 先跑顺现场 |
| **G** | 约 25～30 秒 | 行业泛化 | 中小微企业；按需深定制 |

**执行建议**：优先拍 **B + C**（视觉冲击强、产品特征清晰），再补 **A / E** 做痛点与停留率测试。  
**每条怎么录、怎么展示、口播全文**：见 **§5～§6**。

## 5. 通用录播、剪辑与展示规范

以下适用于全部脚本；先统一做一次环境与数据准备，再按各条截取或补录。

### 5.1 环境与设备

| 项目 | 建议 |
|------|------|
| **主机** | 运行本软件的电脑一台（Electron 窗口 + 内置服务已启动）。 |
| **第二台设备**（脚本 B、部分 A/E/G 需要） | 手机或另一台电脑，**同一局域网**，用 Chrome / Edge / Safari 访问标题栏显示的 `http://内网IP:端口`。提前登录好测试账号，避免录屏时输密码过长。 |
| **录屏软件** | macOS：QuickTime 屏幕录制、OBS、CleanShot 等；Windows：OBS、Xbox Game Bar。分辨率建议 **1920×1080** 或更高，后期再裁竖屏。 |
| **音频** | 口播可用手机录音或无线麦，**单独录一条干声**，后期与画面对齐；环境保持安静。 |
| **扫码**（脚本 C） | 若有扫码枪，焦点落在标签打印页搜索框，扫一条**已在物料库**的码；若无硬件，可**键盘快速输入物料号 + 回车**，剪辑时配「滴」音效。 |

### 5.2 软件与数据准备（录前检查）

1. **应用已启动**，能展示访问地址（标题栏、或本机浏览器地址栏录 `http://局域网IP:端口`）。  
2. **演示账号**已登录；物料库至少有 **3～5 条**好认的测试物料，避免真实客户敏感信息。  
3. **标签打印页**：能搜到目标物料，预览区正常出标签。  
4. **打印**：可到系统打印对话框**停在预览/选打印机**，或真打一张；打印机名称含隐私可打码。  
5. **库存 / 操作记录**（脚本 E/G）：界面脱敏；展示数字或列表即可。  

### 5.3 画面怎么展示（构图与比例）

| 类型 | 做法 |
|------|------|
| **横屏 16:9** | 全屏录应用窗口；重点操作时用剪辑软件**局部放大**（约 1.05～1.15 倍）跟随鼠标。 |
| **竖屏 9:16**（抖音/视频号） | 录屏用较高分辨率整屏，后期**裁中间区域**保证侧边栏 + 主内容在画幅内；或录屏时窗口缩窄。 |
| **画中画** | 口播出镜：人物占下方约 1/3，屏幕占上方约 2/3。 |
| **节奏** | 单镜头不宜超过 **3～4 秒**；转场用 **硬切** 或 **0.2s 闪白**。 |

### 5.4 统一片尾（可选）

最后一帧：**产品中文名 + 一句 Slogan**（如「库存与标签，一站协同」），停留 **0.8～1.2 秒**。

### 5.5 全系列共用素材清单

| 镜头 | 用途 |
|------|------|
| 标题栏或浏览器中的局域网地址 | 「一台电脑、多人浏览器」 |
| 第二台设备浏览器已登录 | 「零安装」 |
| 标签打印：搜索/扫码 → 数量/模板 → 预览 | 核心操作 |
| 打印对话框或出纸 | 动作闭环 |
| 库存数字、操作记录、侧边栏切换 | 辅助记忆点 |

## 6. 各条视频详细执行稿（录播 · 展示 · 口播）

以下为 **A～G** 每条独立成篇。口播可略口语化；**总时长以手机秒表念一遍**为准，落在各条标注区间。

---

### 脚本 A｜Excel 地狱 → 一系统（痛点型）

| 项目 | 内容 |
|------|------|
| **时长** | 约 18～22 秒 |
| **一条信息** | 工具分散 → 一套系统；浏览器访问 |

**怎么录**

1. **A1（可选）**：录 **Excel 快速滚动** 或 **聊天列表划过**（脱敏），**1.5～2 秒**。若无，用 **多窗口快速切换** 制造「乱」。  
2. **A2**：从 Dock/任务栏 **点开本软件**，进入清爽主界面，**约 1 秒**。  
3. **A3**：侧边栏进入 **标签打印** 或 **入库**，展示结构化列表 **2～3 秒**。  
4. **A4**：切到 **第二台设备浏览器**，地址栏可见内网地址，已登录首页 **2～3 秒**。  

**怎么展示**

- 开头段落：快切 + **略降饱和度**或**轻微故障线**表现「乱」。  
- 进入软件后：**正常饱和度**，可加细边框突出「一套系统」。  
- 口播到「浏览器」时：**放大地址栏**或字幕打出 `http://192.168.x.x:端口`。

**怎么介绍（口播建议全文）**

> 「库存还在 Excel 里猜？入库、出库、标签——一个系统对齐。局域网里打开浏览器就能用，不用每人装软件。中小微企业，先把账和标签跑顺。」

**后期**

- 开头可加打字机或「叮」；转场至浏览器可加短 **Swoosh**。  
- 片尾定帧产品名。

---

### 脚本 B｜一台服务端 · 零安装（数字/地址型）

| 项目 | 内容 |
|------|------|
| **时长** | 约 15～18 秒 |
| **一条信息** | 一台电脑当服务；全员浏览器 |

**怎么录**

1. **B1**：主窗口最大化，**镜头指向标题栏**或含访问地址的区域；若无标题栏地址，录 **本机浏览器** 打开 `http://127.0.0.1:端口` 或局域网 IP **2 秒**。  
2. **B2**：**手机或第二台电脑**录屏：仅 **浏览器**，从打开到登录后首页 **3～4 秒**。  
3. **B3**：回到主窗口，侧边栏 **快速点 2～3 个菜单**（如标签打印、入库、库存），每处停留 **约 0.8 秒**，供后期硬切蒙太奇。  

**怎么展示**

- 开场可加 **黑底白字全屏**：「一台电脑 · 全员在线」**约 0.8 秒**，再进实拍。  
- 地址栏建议 **关键帧放大**。

**怎么介绍（口播建议全文）**

> 「一台电脑开机，全员在线。同事只输地址——零安装。打印、库存、配货，跟现场一条线。」

**后期**

- 「一」字可做 **大字震动**强调；BGM 可选轻电子 **100～110 BPM**。

---

### 脚本 C｜扫码到打印（动作型）

| 项目 | 内容 |
|------|------|
| **时长** | 约 20～26 秒 |
| **一条信息** | 扫码 → 打印闭环；打印与库存联动 |

**怎么录**

1. 进入 **标签打印**，焦点在搜索框。  
2. **扫码**或输入物料号 → **选中结果**。  
3. 调 **物品数量、打印张数**，切换 **小标签/大标签**（若有）各 **约 1 秒**。  
4. 右侧 **预览** 停留 **2 秒**。  
5. 点击 **「打印标签并扣减库存」**（或等价按钮），录 **打印对话框** 或 **出纸**。  
6. （可选）剪 **库存页** 数字与打印动作 **交叉 1 秒**。  

**怎么展示**

- **跟随鼠标** 轻微放大画面中心；预览区占画幅 **≥40%**（竖屏也清晰）。  
- 「扫码」瞬间可 **闪白 2 帧** + 「滴」音效。

**怎么介绍（口播建议全文）**

> 「扫码。选数量。预览。打印——库存跟着扣。标签不是贴纸，是台账的一步。」

**后期**

- 四字短句与画面 **一一硬切**；最后一句人声清晰，BGM 压低。

---

### 脚本 D｜系统适应人（理念型）

| 项目 | 内容 |
|------|------|
| **时长** | 约 22～28 秒 |
| **一条信息** | 不强迫改流程；按需定制与数字化 |

**怎么录**

1. **D1**：剪辑加全屏大字：**「别改流程」** 或 **「先别上大 ERP」**，**2 秒**。  
2. **D2**：**仓库/工位空镜** **3 秒**（可自拍）；若无，全屏软件 + 列表滚动营造现场感。  
3. **D3**：软件内 **表单、列表、配货单** 等 **2～3 个页面快切**，每段 **2～3 秒**。  

**怎么展示**

- **字幕为主**：关键词 **黄底黑字或粗体**。  
- 避免长时间静止；**列表滚动、Tab 切换**保持动势。

**怎么介绍（口播建议全文）**

> 「别让员工去适应一套大而全。我们要的是——系统适应你现在的习惯。库存数字化，从你最痛的那一段开始。」

**后期**

- BGM 陈述感、不抢戏；「最痛的那一段」可配轻鼓点。

---

### 脚本 E｜账实一致之问（质问型）

| 项目 | 内容 |
|------|------|
| **时长** | 约 15～20 秒 |
| **一条信息** | 留痕、协同、少扯皮 |

**怎么录**

1. **E1**：**真人出镜停顿**或 **黑屏大字** **0.8 秒**（质问前置）。  
2. **E2**：**库存页**，鼠标划过若干行数字。  
3. **E3**：**操作记录**列表滚动 **2～3 秒**（脱敏）。  
4. **E4**：**主窗口 + 手机浏览器** 各 **1.5 秒** 分屏或前后相接。  

**怎么展示**

- 质问句：**居中粗字**，黑底白字或红字强调。  
- 「留痕」：**略慢放** 展示一行（操作人、时间）。

**怎么介绍（口播建议全文）**

> 「你最后一次账实一致，是哪天？打印自动扣减，出入库留痕——少一次扯皮。一台服务端，全员浏览器协同。」

**后期**

- 前 3 秒可无 BGM，突出人声。

---

### 脚本 F｜金句快闪（最短测试款）

| 项目 | 内容 |
|------|------|
| **时长** | 约 12～15 秒 |
| **一条信息** | 工具散 → 先跑顺现场 |

**怎么录**

1. **镜1（3～4s）**：标签打印 **搜索 + 出结果**。  
2. **镜2（3～4s）**：**预览区** 特写。  
3. **镜3（3～4s）**：**浏览器访问** 或 **侧边栏图标快切**。  
4. 可先 **只录画面**，口播后期叠加。  

**怎么展示**

- **快闪**：平均 **1.2～1.5 秒/镜**，最后 3 秒略放慢。  
- 可轻微 **缩放脉冲** 增动感。

**怎么介绍（口播建议全文）**

> 「库存不准，往往不是人不行，是工具太散。标签打印、库存、局域网协同——先把现场跑顺。」

**后期**

- 字幕 **全出**；结尾定帧 Slogan。

---

### 脚本 G｜中小微企业 · 泛化（信息较多）

| 项目 | 内容 |
|------|------|
| **时长** | 约 25～30 秒 |
| **一条信息** | 不是更大 ERP，而是跟得上现场；按需定制 |

**怎么录**

1. **G1**：剪辑大字 **「中小微企业」** **1.5 秒**。  
2. **G2**：**乱 → 齐** 转场：Excel 或杂窗口 **0.8 秒** **叠化** 到软件 **2 秒**。  
3. **G3**：**功能蒙太奇**：标签打印 → 入库 → 出库 → 配货单 → 库存 →（可选）用户管理，每模块 **2～3 秒**，总长 **12～15 秒**。  
4. **G4**：结尾定帧文案：**「先解决最痛的一段，再谈数字化」**。  

**怎么展示**

- 蒙太奇时画面 **右侧固定小标题**（如「标签」「入库」「配货」），便于观众跟上。  
- 每模块 **不展开操作**，点到为止。

**怎么介绍（口播建议全文）**

> 「中小微企业最缺的，不是更大的 ERP，是一套跟得上现场的系统。标签、入库出库、配货、权限、记录——按需深定制。先解决最痛的一段，再谈数字化。」

**后期**

- 关键词字幕与口播同步；BGM 压低，句间留短气口。

---

## 7. 标题与投放（可选）

- **标题轮换**：同一视频可配 2～3 个不同标题做测试（痛点型 / 好奇型 / 对立型）。  
- **避免**：首帧长时间静止 Logo、前 3 秒纯口播无画面、单条塞入过多数字与专业词。

---

## 8. 成功标准（简要）

| 维度 | 参考 |
|------|------|
| 制作过程 | 单条成片可稳定控制在 30 秒内；系列可每周固定产出条数。 |
| 传播 | 更关注**完播率、前 3 秒留存**与评论里是否出现「我们也是 Excel」类共鸣，而非单纯播放量。 |
| 商业 | 咨询或试用线索中，能复述出至少一个记忆点（如浏览器访问、打印扣库存）。 |
