# 打印对话框自动确认助手

配货员在 **浏览器 Web** 端批量打印时，系统仍会弹出「打印」对话框。本工具在后台监听或按延时自动按 **Enter**（或点击你校准过的坐标），代替人工点「打印」，解放双手。

> **安全提示**：启用后请勿在批量打印过程中移动鼠标或切换窗口，以免误触其它界面。专用配货工位使用。

## 方式一：桌面端（推荐）

使用本仓库 **Electron 客户端** 时，在「一键打印」或「标签打印」弹窗中勾选 **「打印助手（自动点确定）」** 即可，无需单独运行脚本。

首次在 macOS 上需在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许「库存管理系统」或 Terminal。

## 方式二：纯 Web 浏览器（Windows，推荐「嵌入 Web」）

1. 配货电脑上**双击** `启动打印助手.bat`（或运行 `local-bridge.ps1`），**保持黑窗口不关**。
2. 浏览器打开配货单 → 一键打印弹窗 → 点 **「检测连接」**，显示本机桥接已连接。
3. 勾选 **「打印助手（自动点打印/确定）」** → 开始打印。
4. 网页在每次 `window.print()` 后会请求 `http://127.0.0.1:39217/confirm`，由本机桥接自动按 Enter。

无需 `-Watch` 循环模式；由网页驱动，体验与「嵌在页面里」一致。

### 备用：Watch 模式（不启桥接时）

```powershell
cd 路径\tapePrinter\tools\print-dialog-helper
.\auto-confirm-print.ps1 -Watch
```

### 参数

| 参数 | 说明 | 默认 |
|------|------|------|
| `-Watch` | 循环监听含「打印/Print」的窗口 | 单次模式不需 |
| `-DelayMs` | 检测到窗口后延迟再按键 | 600 |
| `-TitleHint` | 窗口标题包含的文字 | 打印 |

若 Enter 无效（部分 Chrome 打印预览），用 **坐标模式**：

1. 双击 `capture-print-button-position.bat`，在 8 秒内打开一次打印弹窗并把鼠标移到「打印」按钮中心。
2. 记下脚本显示的 X、Y。
3. 在「一键打印」弹窗的打印助手区域勾选固定坐标模式，填入 X、Y。

备用命令行方式：

```powershell
.\auto-confirm-print.ps1 -ClickX 1100 -ClickY 500
```

坐标可用「截图 + 画图」量出「打印」按钮中心（相对屏幕左上角）。

## 方式三：纯 Web 浏览器（macOS）

```bash
chmod +x auto-confirm-print.command
./auto-confirm-print.command watch
```

需在 **辅助功能** 中允许 Terminal 或脚本宿主。

## 与「合并一次打印」配合

- 仅跑本助手、不合并：每条标签仍弹一次框，但 **无需手点**（N 次自动确认）。
- **合并打印 + 本助手**：网页只弹 **1** 次框，助手确认 1 次，体验最佳（合并功能需在应用中开启 Web 合并分支）。

## 故障排查

| 现象 | 处理 |
|------|------|
| 没反应 | 加大 `-DelayMs 900`；确认打印框标题含「打印」或改 `-TitleHint Print` |
| 误触其它窗口 | 打印时不要切屏；专用工位关闭 `-Watch` 改用桌面端勾选助手 |
| macOS 拒绝控制 | 系统设置里打开辅助功能权限 |
